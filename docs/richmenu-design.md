# สเปกออกแบบ Rich menu

ภาพ Rich menu 2 รูป (แท็บ **หน้าหลัก** และ **เพิ่มเติม**) — ผู้ออกแบบวางไฟล์ที่:

| ไฟล์ | ใช้กับ |
|---|---|
| `assets/richmenu/main.png` | แท็บหน้าหลัก |
| `assets/richmenu/more.png` | แท็บเพิ่มเติม |

**ข้อกำหนดไฟล์ (ตรวจอัตโนมัติตอนรัน `npm run richmenu:setup`):** PNG, **2500 × 1686 px**, **ไม่เกิน 1 MB**

ภาพช่วยวาง (พื้นหลัง/เลเยอร์ guide ใน Canva/Figma): `assets/richmenu/guide-main.png`, `guide-more.png`
(เส้นประสีแดง = ขอบเขตปลอดภัยของแต่ละปุ่ม เว้นจากขอบ 40 px — อย่าวางตัวอักษร/ไอคอนนอกเส้นประ)
สร้างภาพ guide ใหม่ได้ด้วย `node scripts/richmenu-guide.js` (ต้องมี `rsvg-convert`)

## เลย์เอาต์ (ทั้งสองรูปใช้กริดเดียวกัน)

```
┌──────────────── 2500 ────────────────┐
│  แท็บ หน้าหลัก  │   แท็บ เพิ่มเติม    │  y 0–150   (กว้างข้างละ 1250)
├────────┬─────────┬───────────────────┤
│ ปุ่ม 1 │  ปุ่ม 2 │      ปุ่ม 3       │  y 150–918   (สูง 768)
├────────┼─────────┼───────────────────┤
│ ปุ่ม 4 │  ปุ่ม 5 │      ปุ่ม 6       │  y 918–1686  (สูง 768)
└────────┴─────────┴───────────────────┘
คอลัมน์: x 0–833 | 833–1667 | 1667–2500
```

- **แถบแท็บ (y 0–150):** แท็บที่กำลังเปิดต้องดู "active" ชัดเจน (เช่นพื้นเขียว ตัวขาว) อีกแท็บเป็นสีจาง — แท็บซ้ายใน `main.png` active, แท็บขวาใน `more.png` active
- ปุ่มทั้งหมดต้องดูเป็น "ปุ่ม" ที่กดได้ (การ์ด/พื้นสีมีขอบ) และขนาดเท่ากัน

## ปุ่มและไอคอนที่แนะนำ

**หน้าหลัก** (`main.png`)

| ตำแหน่ง | ข้อความบนปุ่ม | ไอคอนแนะนำ | กดแล้วเกิดอะไร |
|---|---|---|---|
| 1 บนซ้าย | บันทึกค่าใช้จ่าย | 💸 | เปิดคีย์บอร์ดพร้อมคำว่า "ค่า" |
| 2 บนกลาง | สรุปยอด | 📊 | ส่ง `สรุป` |
| 3 บนขวา | จ่าย/รับเงิน | 💳 | บอตถามต่อด้วยปุ่มเลือก (เรียกเก็บ / จ่ายแล้ว / รับแล้ว) |
| 4 ล่างซ้าย | ลบรายการ | 🗑 | ส่ง `ลบรายการ` |
| 5 ล่างกลาง | ทริป | ✈️ | บอตถามต่อด้วยรายชื่อทริป |
| 6 ล่างขวา | ถามข้อมูล | 💬 | บอตเสนอคำถามยอดนิยม |

**เพิ่มเติม** (`more.png`)

| ตำแหน่ง | ข้อความบนปุ่ม | ไอคอนแนะนำ | กดแล้วเกิดอะไร |
|---|---|---|---|
| 1 บนซ้าย | ตั้งแจ้งเตือน | ⏰ | ส่ง `แจ้งเตือนใหม่` (เลือกวันเวลาจากปฏิทิน) |
| 2 บนกลาง | ดูแจ้งเตือน | 📋 | ส่ง `ดูแจ้งเตือน` |
| 3 บนขวา | หาจุดชาร์จ EV | 🔌 | บอตแนะนำวิธี + ปุ่มแชร์ตำแหน่ง |
| 4 ล่างซ้าย | ตั้งค่ารถ | 🚗 | เปิดคีย์บอร์ดพร้อม "ตั้งค่ารถ " |
| 5 ล่างกลาง | สรุปเดือนนี้ | 📅 | ส่ง `สรุปยอดเดือนนี้` |
| 6 ล่างขวา | วิธีใช้ | ❓ | ส่ง `help` |

## แนวทางออกแบบให้อ่านง่ายบนมือถือ

- ข้อความบนปุ่มเป็นภาษาไทย **ขนาด ≥ 90 px** (ภาพนี้ถูกย่อเหลือกว้างราว 360–400 px บนจอ ตัวเล็กกว่า 70 px จะอ่านไม่ออก)
- ไอคอน 1 อัน + ข้อความ 1 บรรทัดต่อปุ่ม — ไม่ใส่คำอธิบายยาว
- คอนทราสต์สูง (ตัวเข้มบนพื้นอ่อน หรือกลับกัน) และสีไอคอนสอดคล้องกันทั้งสองแท็บ
- ปุ่มเรื่องเงิน (จ่าย/รับเงิน) ใช้สีเน้นต่างจากปุ่มอื่นได้ เพื่อให้หาเจอเร็ว
- ถ้าเปลี่ยนชื่อปุ่ม/ลำดับ ให้แก้ที่ `src/richmenu/definitions.js` (ตาราง `BUTTONS`) แล้วรัน `node scripts/richmenu-guide.js` ใหม่

## ติดตั้งบน LINE

dev และ prod ใช้ LINE channel คนละตัว ต้องรันแยกกัน (ตั้ง `LINE_CHANNEL_ACCESS_TOKEN` ของ environment นั้นๆ):

```bash
npm run richmenu:setup -- --dry-run   # ตรวจรูป + โครงสร้างกับ LINE โดยไม่สร้างจริง
npm run richmenu:setup                # สร้าง 2 แท็บ อัปโหลดรูป ตั้งเป็นเมนูเริ่มต้น (รันซ้ำได้)
npm run richmenu:list                 # ดูเมนูที่มีอยู่
npm run richmenu:delete               # ลบเมนูที่เราสร้างไว้
```

ถ้า OA เคยตั้ง Rich menu ผ่าน LINE Official Account Manager ไว้ ให้ปิดอันเก่าก่อน ไม่งั้นอาจชนกับเมนูที่สร้างผ่าน API
